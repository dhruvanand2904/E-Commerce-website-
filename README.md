# Exercise 2 – Static E-Commerce Website (HTML)

## 📌 Objective
To design and develop a **static e-commerce website** using **advanced HTML tags** that simulates a real-world online shopping and order placement process similar to popular platforms like Amazon.

---

## 🛠 Technologies Used
- HTML5  
- Advanced HTML elements  
- No CSS or JavaScript (pure static HTML)
